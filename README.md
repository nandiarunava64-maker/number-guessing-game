# Number Guessing Game 🎯

A simple number guessing game written in C.

## How it works

The computer generates a random number between 1 and 100.

The player tries to guess the number.

The program gives hints:
- Too high
- Too low
- Correct guess

It also counts the number of attempts.

## Language

- C

## How to Run

Compile and run number_guessing_game.c using a C compiler.
